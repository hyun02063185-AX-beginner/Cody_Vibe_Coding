# 럭키 룰렛 바이브코딩 — 심화 프롬프트

[basic-prompt.md](./basic-prompt.md)의 기본 버전은 일부만 잘라 보이는 클로즈업(룰렛이 뒤로 누워 보이면서 위쪽만 크게 잡히는 연출)이나 화려한 다중 링 테두리를 빼놓을 만큼, 테두리가 단순한 평면적인 룰렛을 만듭니다. 시간이 넉넉하고 직접 여러 번 대화하며 고칠 수 있는 학습자라면 아래 두 가지를 추가로 요청해볼 만합니다.

1. **테두리 여러 겹 금색 링**: "진한 금 → 밝은 금 → 진한 금이 번갈아가는 box-shadow를 여러 겹 쌓아서 세공된 금속 베젤처럼" 만들어달라고 요청.
2. **카메라 리클라인(뒤로 누우면서 줌 + 위쪽만 크롭되게)**: "캔버스+테두리를 하나의 wrapper로 묶고, 그 wrapper에만 CSS scaleY로 눕히고, 바깥 wrapper에는 overflow:hidden + scale()로 확대하라"고 명시적으로 요청(이 둘을 하나의 요소에 다 몰아넣으면 테두리가 따로 노는 버그가 납니다).

## 주의

이 두 기능은 여러 겹 요소에 서로 다른 transform을 정확히 나누어 걸어야 해서, 도구가 한 번에 제대로 만들 확률이 낮습니다. 로컬(`python -m http.server` 등)로 띄워서 실제로 스핀 버튼을 눌러보면서 눈으로 확인하고, 이상하면 "이 부분만 이렇게 고쳐줘"라고 구체적으로 집어서 반복 요청하는 식으로 접근하세요. 발표 당일 라이브로 처음 만들 때는 이 심화 버전보다 [기본 버전](./basic-prompt.md)을 권장합니다.

# Cody Vibe Coding — 럭키 룰렛 바이브코딩 강의 자료

2026 제2회 대한민국 강사 강의 뽐내기 대회 발표용 "바이브코딩 라이브 데모" 자료 모음입니다. 주제는 럭키 룰렛(랜덤 뽑기) 웹앱을 AI와 함께 그 자리에서 만드는 것입니다.

## 구성

- **`app/wheel-picker.html`** — 완성된 쇼케이스 참고 구현체(카지노풍 럭키 룰렛). 발표 마지막에 "완성본 공개"용으로 미리 열어두는 폴백 버전입니다.
- **`prompts/basic-prompt.md`** — 교육생에게 배포하는 기본 프롬프트, 실행 방법, 버그 대응법 5단계, 트러블슈팅 팁.
- **`prompts/advanced-prompt.md`** — 여유가 되는 학습자를 위한 심화 프롬프트(다중 링 테두리 + 카메라 리클라인 효과).
